The evaluation script, not the Worker, runs the command and writes `execution.json`, stdout, stderr, the exit code, copied inputs, and all actual output files. Do not create or edit `tool_calls.jsonl` or `execution.json`.

Read the assigned case, the preserved output files, and the CLI contract. Use the real exit code and artifacts only. 不要伪造坐标、图像、来源、成功状态或文件。

Explain candidate observation windows as geometric results only. Explicitly leave weather, clouds, horizon obstructions, equipment readiness, supervision, and observing safety for human confirmation.
