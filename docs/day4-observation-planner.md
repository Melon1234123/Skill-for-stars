# 第 4 天：观测计划与可视化运行记录

## 输入与规则

本阶段直接读取第 3 天的 `runs/day3_m42/intermediate/ephemeris.json`，不重新查询 SIMBAD，也不重复计算目标、太阳和月亮的 AltAz 坐标。

本次 M42 北京案例使用两条可配置规则：

- 目标高度角不低于 30 度；
- 太阳高度角不高于 -12 度。

两个边界都包含等号。每个采样点独立保存判断结果和失败原因：

- `target_below_minimum_altitude`：目标低于最低高度；
- `sun_above_maximum_altitude`：太阳高于暮光上限。

一个采样点可以同时记录两个原因。连续合格采样点合并为候选窗口；窗口起止时间是首尾合格采样时刻，没有对两个 10 分钟采样点之间的真实过阈值时刻做插值。

## 月光证据

月光没有作为第三条布尔门槛。规划结果为每个时刻保留：

- 月面照明比例；
- 月亮高度角；
- 月亮与 M42 的角距离。

候选窗口内的证据范围为：

| 证据 | 窗口起点 | 窗口终点或范围 |
| --- | ---: | ---: |
| 月面照明比例 | 0.518062 | 0.495212 |
| 月亮高度角 | -52.995909 度 | 最高 5.430397 度 |
| M42 与月亮角距 | 最小 110.292497 度 | 最大 112.915508 度 |

照明比例约为一半并逐渐减小。月亮在窗口大部分时段位于地平线下，接近窗口末尾时升到地平线上方；角距较大。这些数值是供教师或使用者复核的证据，不直接替代对天空背景、透明度和设备的判断。

## 图表

`runs/day4_m42/figures/visibility_curve.png` 由 Matplotlib 3.10.9 的对象接口生成，使用 Agg 非交互后端。图中包含：

- M42、太阳和月亮的高度角曲线；
- 目标 30 度阈值线；
- 太阳 -12 度暮光阈值线和不合格暮光区；
- 候选观测窗口阴影。

PNG 固定为 1800×900 像素，白色背景。保存后在 `finally` 中关闭 Figure，避免批量任务积累图形对象。图表直接接收与 CSV/JSON 相同的 `ObservationPlanResult`，没有第二套判断或重新计算路径。

## 输出文件

- `runs/day4_m42/intermediate/visibility.csv`：49 个样本的角量、月面照明比例、判断和失败原因；
- `runs/day4_m42/result.json`：阈值、源星历设置、全部样本和候选窗口；
- `runs/day4_m42/figures/visibility_curve.png`：固定尺寸高度角曲线。

CSV 固定为 10 列，角度和照明比例保留 6 位小数。JSON 保留第 3 天的 Astropy 版本、UTC 时间尺度、AltAz 坐标系、折射和 IERS 下载策略。

## 复现命令

```powershell
python -m starskill plan runs\day3_m42\intermediate\ephemeris.json `
  --output runs\day4_m42\intermediate\visibility.csv `
  --metadata runs\day4_m42\result.json `
  --figure runs\day4_m42\figures\visibility_curve.png `
  --min-target-altitude-deg 30 `
  --max-sun-altitude-deg -12
```

## 自动化验收与限制

测试覆盖全晚不可见、多个分段窗口、恰好等于阈值、同时违反两条规则、月面照明比例、CSV/JSON 契约、无效阈值、PNG 尺寸、非空白像素和 Figure 关闭。

当前限制：

- 窗口边界精度受 10 分钟采样间隔限制；
- 高度角不包含大气折射，观测点海拔仍按 0 米；
- 不读取天气、云量、光污染、地平线遮挡和设备视场；
- 当前只生成候选窗口，第 5 天再串联完整流水线、运行日志、报告和人工复核清单。
